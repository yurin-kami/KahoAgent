# Redis 缓存实战

本文档用于 Phase 1 端到端验证，内容为纯中文，用于检查分块后是否出现乱码。

## 缓存穿透

缓存穿透指查询一个数据库中不存在的数据。由于缓存不命中，每次请求都会打到
数据库上，恶意构造大量不存在的 key 会直接把数据库压垮。

### 布隆过滤器

布隆过滤器是一个概率型数据结构，能以极小的空间判断某个元素「一定不存在」
或「可能存在」。把所有合法 key 预先写入布隆过滤器，查询时先过一遍，
判定不存在就直接返回，请求根本到不了数据库。

代价是有误判率：可能把不存在的 key 判成存在，但绝不会把存在的判成不存在。
这个方向的误判是安全的，最多是多查一次数据库。

### 空值缓存

另一种做法是把「查不到」这个结果本身也缓存起来，设一个较短的过期时间。
实现简单，但如果攻击者每次用不同的 key，缓存里会堆积大量无用的空值。

## 缓存击穿

缓存击穿是指某个热点 key 恰好过期的瞬间，大量并发请求同时打到数据库。
与穿透的区别在于：这个 key 是真实存在的，只是刚好失效了。

常见解法是互斥锁：只放一个请求去重建缓存，其余请求等待。

## 缓存雪崩

缓存雪崩指大量 key 在同一时刻集中过期，数据库瞬间承受全部流量。
解法是给过期时间加一个随机抖动，把失效时间打散。
