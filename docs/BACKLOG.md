## 永久搁置

| 想法 | 搁置理由 |
|------|---------|
| Multi-Agent 编排 | 单 Agent 满足需求，多 Agent 是过度设计，面试反而会被追问「为什么需要多个」 |
| Embedding 模型微调 | 成本极高收益不确定，混合检索的性价比高得多 |
| 语义分块（按 embedding 相似度切） | 每句都要 embed，成本 10 倍，效果提升有限 |
| MCP Resources / Prompts 原语 | Tools 已覆盖全部需求 |
| OAuth 认证 | 个人项目 API Key 足够，OAuth 是企业多租户场景 |
| NDCG 等复杂评估指标 | Recall@K + MRR 已能说明问题 |
